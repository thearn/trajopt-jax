## 1. Architecture

`trajopt_jax`, in dependency order: `specs.py` and `events.py` (state, control and path-constraint specs; mission events and legs) -> `radau.py` and `stages.py` (Radau IIA stage transcription, chained missions, co-design) -> `riccati.py` (sequential and parallel Riccati recursions) -> `ipm.py` (the interior-point solver) -> `refine.py`, `envelope.py`, `batch.py` (mesh refinement, the optimum's sensitivity to model data, batched starts); `problem.py`, `result.py`, `reference.py` (the protocol, the result record, a dense reference solver).
